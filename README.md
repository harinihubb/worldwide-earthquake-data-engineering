🌍 **Project Completed: An End-to-End Worldwide Earthquake Data Engineering using Microsoft Fabric**

I'm excited to share my latest hands-on project, where I built an end-to-end data engineering and analytics solution using **Microsoft Fabric** and the **USGS Earthquake API**.

The project focuses on processing worldwide earthquake event data using the **Medallion Architecture**, with three data layers:

🔹 **Bronze Layer:** Ingesting and storing raw earthquake data from the USGS API.

🔹 **Silver Layer:** Cleaning and transforming the ingested data.

🔹 **Gold Layer:** Preparing analytical datasets for reporting and visualisation.

⚙️ **What I implemented:**
- API-based data ingestion using Python.
- Data transformation using PySpark.
- Geographic enrichment using Reverse Geocoder.
- Lakehouse-based data organisation in Microsoft Fabric.
- Data Factory pipeline orchestration to execute the Bronze, Silver, and Gold notebooks sequentially.
- Power BI dashboard to explore earthquake distribution, magnitude, significance, trends, and severity classifications.

This project helped me gain practical experience with data ingestion, data transformation, Medallion Architecture, pipeline orchestration, and business intelligence.

**Technologies:** Microsoft Fabric | Python | PySpark | USGS API | Power BI
